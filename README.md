# Kwacha Escrow

Secure USDT P2P escrow trading platform for Malawi.

## Features

- P2P USDT trading with escrow protection
- Supports TRC20 (Tron) and BEP20 (BSC) networks
- Mobile money, bank transfer, and cash payment methods
- KYC verification system
- Reputation and rating system
- Admin dispute resolution panel
- 0.8% escrow fee per completed trade

## Tech Stack

- React + Vite
- Tailwind CSS
- Supabase (Auth + Database)
- Vercel (Deployment)

## Setup

1. Clone the repo
2. `npm install`
3. Copy `.env.example` to `.env` and fill in your Supabase credentials
4. Run `supabase_schema.sql` in your Supabase SQL editor
5. `npm run dev` to start the dev server
